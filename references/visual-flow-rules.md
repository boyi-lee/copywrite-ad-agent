# Visual Flow Rules for Meta Ads

## Core Principle

Meta ad copy is not read in isolation. The user usually sees the creative first, then text on creative, then the ad headline, then the primary text, then CTA. Copy must work as one sequence instead of repeating the same promotional message in every field.

## Reading Order

1. Image or video
2. Text on creative
3. Ad headline
4. Primary text
5. CTA button
6. Landing page

## Do Not Repeat

If the creative already communicates a message, the copy should not repeat it word-for-word or paraphrase it as the main hook.

Bad:

Creative says: 最後倒數
Primary text says: 618 最後倒數，錯過不再

Why bad:

- Wastes the shopper's attention.
- Adds no purchase logic.
- Makes the ad feel like a template.

Better:

Creative says: 最後倒數
Primary text adds: 看過還沒下手的款式，可以先從常穿、好搭、尺寸容易被挑走的品項開始。折扣不是為了亂湊件，是把平常會穿的裝備一次補齊。

## Copy Should Add One of These

Primary text should add at least one:

1. Product reason
2. Buyer scene
3. Objection handling
4. Timing reason
5. Category route
6. Bundle logic
7. Price framing
8. Social proof, only if verified
9. Specific user identity
10. Next action clarity

## Visual-to-Copy Continuity

The copy should feel like the next useful sentence after the creative.

If the visual says `618 年中慶`, copy can continue with:

不是只看折扣，這波更適合補齊平常很少一次買齊的實穿款。

If the visual says `最後倒數`, copy can continue with:

還在猶豫的通常不是不想買，是不知道先挑哪件。先從常穿、常用、尺寸容易被挑走的品項開始。

If the visual shows golf shoes, copy can continue with:

早場、濕草地、長時間走動，鞋子的穩定跟舒適會比你想得更有感。

If the visual shows apparel, copy can continue with:

下場、練球、賽後行程都會穿到的單品，才值得趁活動一次補齊。

## Meta Field Roles

Primary text:
- Adds context, buyer scene, product value, selection route, objection handling, or action reason.

Headline:
- Adds a short browsing or benefit cue. It should not simply restate the offer if the creative already does.

Description:
- Reduces click uncertainty with a browsing cue, category cue, or offer confirmation.

CTA:
- Must match the available platform action, such as Shop Now, Learn More, or Sign Up.

## Common Mistakes

Avoid:

- Repeating the promotion in every field.
- Repeating the headline in the primary text.
- Starting with generic slogans.
- Using urgency without reason.
- Writing copy that could fit any brand or category after replacing the name.
- Ignoring the product shown in the creative.
- Writing Collection exploration language for a Carousel.
- Writing Carousel swipe language for a Collection.
