# 通用避免 AI 味文案過濾規則 (Anti-AI Copy Rules)

## 模組說明
本檔案提供 AI Agent 執行自我修正（Self-correction Loop）時的硬性負向限制（Negative Constraints）。旨在過濾掉 ChatGPT / Gemini 預設最喜歡使用的「官網大氣口號腔」與「無摩擦感完美廢話」，確保文字自然、像個真人在說話[cite: 3, 5, 7]。

## anti_ai_rule:
  bad_pattern: 濫用排比句「不僅能……更是……、讓我們一起……攜手共創……」
  why_bad: AI 預設極度喜歡使用這種整齊對稱、大氣卻毫無意義的企業願景腔。在網路、社群與直效銷售環境中，會產生極強的「機器人業配感」，讀者的大腦會瞬間將其判定為無形玻璃直接略過[cite: 3, 5, 7]。
  replace_with: 刻意不對稱的句子長度、帶有心理摩擦感的「欲揚先抑」對話、或者加入「你字互動」[cite: 2, 3]。
  weak_example: 「本軟體不僅能為您提供卓越的財務對帳技術，更是您在數位轉型潮中點燃激情、打造高效人生的不二選擇。讓我們一起攜手，共創未來的輝煌！」[cite: 3, 5, 7]
  better_example: 「老實說，這套系統剛上線時會計也有點懷疑，畢竟外觀跟常規軟體差不多。但到了月底實測一鍵結帳，原本要抓頭苦思 3 天的異常帳目，30 秒內就自動核對完成了。討厭月底對帳加班到出冷汗的主管，這套真的很值得試試看[cite: 2, 3, 4, 5, 7]。」
  review_check: 檢查文案中是否包含「不僅能……更是……、攜手、共創、完美融合」[cite: 3, 5, 7]？大聲朗讀時，聽起來像不像宣傳手冊[cite: 3, 5]？如果是，一律打回改寫。

## anti_ai_rule:
  bad_pattern: 過度正向、毫無生活摩擦感與抗拒點（完美世界綜合症）
  why_bad: AI 寫的文案往往像活在完美的真空包裝裡，每個人都積極向上、每個產品都完美無瑕。這種沒有「 Shopper Tension（消費者不滿/焦慮/吐槽）」的文案，無法在邊緣系統中引發任何共鳴，因為與現實生活完全脫節[cite: 2, 3, 4, 7]。
  replace_with: 融入目標客群生活中真實存在的吐槽、困難、敢怒不敢言的現狀、或是競品的糟糕體驗（求證用戶痛點）[cite: 2, 4, 7]。
  weak_example: 「本款保濕面膜能帶給您最美麗、最時尚的護膚體驗，讓您的肌膚煥發生機，迎接美好的一天。」[cite: 3, 7]
  better_example: 「明明火鍋、宵夜一起吃，眼看我的小肚腩日漸凸起、肥肉越積越多，可恨的是我隔壁桌的同事卻絲毫沒變腫，依然苗條如初？（自爆不滿反差）[cite: 2, 4]」
  review_check: 文案中是否只有一味的讚美與自嗨羅列[cite: 2]？是否有幫受眾把內心想說卻不敢說、不好意思說的話「直率地替其表達出來」[cite: 4, 5]？
