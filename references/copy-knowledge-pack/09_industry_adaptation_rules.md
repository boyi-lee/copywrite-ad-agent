# 跨產業文案特徵與遷移規則 (Industry Adaptation Rules)

## 模組說明
本檔案提供 AI Agent 針對不同產業類型的核心心理學底層邏輯與特徵加權。AI 必須在收到 brief 產業標記後，自動調整說服拉桿的情緒濃度與理性藉口比例[cite: 2, 4]。

## rule:
  name: B2B SaaS / 企業軟體與專業服務遷移規則
  universal_or_contextual: contextual
  applies_to: B2B 企業採購提案、SaaS 產品頁、技術白皮書、B2B 開發信。
  not_suitable_for: B2C 潮流美妝時尚、快消品電商促銷[cite: 2, 7]。
  how_to_apply:
    1. 大腦結構雖然相同（同樣有邊緣系統與眶額皮質），但 B2B 採購者（如：會計、總務、執行長）在做決定時面臨的不是「個人渴望」，而是「組織風險成本與決策錯誤被上司責備的恐懼」[cite: 2, 3]。
    2. 嚴禁使用「全網最酷、點燃激情、奢華享受」等感性詞彙[cite: 3, 7]。必須將利益點（Benefit）高度鎖定在：**降低風險、改善時間成本、提升工作流效率、避免法律合規漏洞**[cite: 2, 3, 4]。
    3. 說服論證必須嚴謹提供 EPL 大腦模型中的「邏輯（Logos）」，例如：冷碳回火般的技術步驟細節、MarTech 數據報告、SGS/FDA等權威背書，以此作為他們向董事會或老闆合理化採購決策的「理性藉口」[cite: 2, 3, 4]。
  weak_execution: 「本款智能排班系統功能強大，能為您的企業帶來全新、完美、卓越的高效體驗，點燃員工熱情。」[cite: 3, 7]
  strong_execution: 「月底手動對帳只要出錯一次，面臨的就是稅務機關的查核與巨額罰款風險。這套自動化財務系統符合歐盟安全合規標準，能幫會計自動核對 98.7% 的跨國帳目，把原本要抓頭苦思 3 天的行政手續濃縮成 30 秒一鍵生成（優點），讓您的經理有空專注在真正能幫公司獲利的戰略業務上（意義）。」
  review_check: 文案中是否出現了無法量化的空泛自嗨詞（如：完美、最卓越）[cite: 2, 3, 7]？是否有為採購者提供足以向上司匯報的「組織效率/合規證據」[cite: 2, 3]？

## rule:
  name: 線上課程 / 線上教育 / 知識付費遷移規則
  universal_or_contextual: contextual
  applies_to: 線上課程 Landing Page、個人品牌引流、招募說明會、MarTech 教育課程。
  not_suitable_for: 實體快消品電商一鍵加購。
  how_to_apply:
    1. 教育課程是虛擬的，看不見摸不著，受眾購買時最大的阻力（Shopper Tension）是：「我買了沒時間上、我資質不好學不會、這是不是割韭菜」[cite: 2, 4]。
    2. 文案的核心任務是：**不要長篇大論去羅列冷冰冰的課程大綱（Feature），而要描述學員學完後「能力的具體變化」與「理想生活場景」[cite: 2, 4, 7]。**
    3. 標題與開場優先使用「故事反差句型」：講師自身低起點到高成就的境遇反差，或老學員「六十二歲老奶奶也能速成英語達人」的客戶回饋反差，在無意識中給予受眾積極的心理暗示：「連他都能學會，那我肯定也可以」[cite: 2, 4]。
    4. 必須在結尾提供「紅利與甜頭」：送可以直接複製套用的範本、案例集、圖標、工具箱，降低其「學習成本與行動成本」[cite: 2, 3, 4]。
  weak_execution: 「本數位行銷課程總共包含 20 堂課，由名師授課，從基礎到進階，大綱內容非常豐富，歡迎點擊選購。」[cite: 2, 7]
  strong_execution: 「從收拾好桌面到打開 Word 大腦一片空白，寫作最難的是跨出第一步（Before）。這堂課不教生硬的文法，我們直接送你 31 個可直接複製的吸金文案產生器範本，讓兼職創作者只要花 15 分鐘填空回答問題，就能自動生成高點擊率標題。即使你高中英文被當、討厭寫作，也能靠這套藍圖無風險開始你的個人品牌第一步（After/無風險承諾）[cite: 2, 4]。」
  review_check: 文案是否只是在死板地貼出 20 章節的課綱？是否有給出直接拿來應急的「範本/工具箱紅利」[cite: 2, 4]？是否有利用學員反差來降低其學不會的恐懼[cite: 2, 4]？
