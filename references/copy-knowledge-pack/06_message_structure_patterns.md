# 通用文案訊息結構句型庫 (Message Structure Patterns)

## 模組說明
本檔案提供 AI Agent 組織長短篇文案、Landing Page 段落、或影片有聲腳本正文時的通用結構模板。

## pattern:
  name: 拔刺防禦型原理解析結構 (The Objection-Defusing Explainer)
  summary: 當文案向受眾提出一個新穎、高價或高難度的概念時，受眾內心會出現「這不可能、對我沒用」的 Shopper Tension[cite: 4]。此結構透過主動暴露缺點與細節自查，反轉大腦的防禦機制作為說服證據[cite: 2, 4]。
  universal_or_contextual: universal
  applies_to: MOFU 建立理解、B2B SaaS 核心賣點轉譯、高端品牌質感論述、專業服務提案[cite: 2, 4, 7]。
  not_suitable_for: 低單價快消品（如：面紙、抹布）的一鍵加購活動（此時會拉長決策時間，降低轉換）[cite: 3, 7]。
  how_to_apply:
    1. 主動提出受眾最想指控、懷疑、不信任的產品特定環節（拔刺）[cite: 4]。
    2. 用科學或生物學、物理學常識給出「無色無味、費時費力、成分含量低但吸收高」的客觀自查標準（講人話，不自嗨）[cite: 2, 4]。
    3. 藉由「對比傳統競品糟糕的點」，讓受眾在大腦中為你的真誠而自我辯護，進而深信不疑[cite: 2, 4]。
  examples:
    - example:
        industry: 個人品牌
        platform: Landing Page
        funnel_stage: MOFU
        copy_task: 服務說明內文
        text: |
          「你可能會懷疑：這套個人諮詢費比市場均價高出了 3 倍，是不是在吹牛？
          
          說實話，我沒辦法在 1 小時內教你什麼大師級神話。我的諮詢大綱只專注在三件事：外觀自查、感官體驗、物理試驗。
          
          市面上大多數教你經營個人品牌的人，只會給你一堆生硬的專有名詞、要你大量洗流量；但這套方法是教你如何找出那些藏在產品背後、連你自己都忽略的費時費力代價（超級賣點），把它翻譯成連小學生都能聽懂的人話。我們不賣空泛的口號，只賣能直接幫你提高 30% 利潤的實戰說服底層邏輯[cite: 2, 4]。」
        why_good_or_bad: 藉由自爆「不便宜、不是神話」的小缺點，贏得完全的主導權，讓讀者理智降溫並全面信任[cite: 2, 4]。
        reusable_rule: 拔刺 ＋ 評判標準定義 ＋ 獲得感量化[cite: 2, 4]。
        caution: 必須在後方給出 4R 的無風險承諾或退款保證[cite: 3, 4]。
  weak_execution: 「我們擁有最厲害、最領先、品質頂級的專業諮詢服務，適合所有想要成功的創業者。」[cite: 2, 3, 7]
  strong_execution: 「一開始你可能完全無感（自爆小缺點），因為這套系統不含任何即時遮瑕的高分子白油。我們光是為了找到符合歐盟檢測的植物活性，就打樣了 100 多次。前三天你的肌膚只會覺得清爽、沒負擔；第 28 天後，你才會發現毛孔自然收緊的驚喜改變（體驗具象化）[cite: 2, 4, 5]。」
  review_check: 文案中是否在使用「最棒、最完美」等無法給出客觀標準的極限詞[cite: 2]？是否主動指出了顧客內心正在懷疑的抗拒點[cite: 4]？
