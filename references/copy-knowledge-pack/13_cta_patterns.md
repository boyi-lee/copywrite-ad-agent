# 通用行動呼籲句型庫 (CTA Patterns)

## 模組說明
本檔案供 AI Agent 撰寫文案結尾的行動呼籲（Call to Action）。要求完全從「顧客的角度（獲得感/承諾）」撰寫，拒絕乾巴巴的行政指令字眼（如：購買、送出、點擊此處）[cite: 3, 4, 7]。

## 1. 核心撰寫原則 (CTA Rules)
*   **拒絕使用「如果/如欲」**：絕不寫「如果您有需要，請點擊……」這隱含著受眾不一定要買、不一定要行動。必須直接使用主動、肯定的祈使語氣或未來結果預測[cite: 3, 4]。
*   **以顧客（我）為主體**：將行動按鈕或文案寫成受眾採取行動後的利益承諾，而非公司收錢的動作（如：把「立即購買」改成「我要無風險帶走一整套」）[cite: 3, 4]。
*   **結合 4R 催單機制**：在 CTA 旁邊或附註（P.S.）中，加入一再保證（Reassure）與心理帳戶偷換，徹底消除花錢負罪感[cite: 3, 4]。

## 2. 跨產業通用 CTA 句型 (CTA Patterns Matrix)

### pattern:
  name: 情感利益獲得型 CTA
  structure: 「我要 [解決痛苦的動作/獲得理想場景] ！」 ＋ 【點擊現折 100 元 / 30天無風險試用保證】[cite: 3, 4]
  examples:
    - 「我要月底準時下班，徹底告別手動對帳！」【立即免費體驗 14 天完整版系統】(B2B SaaS 適用)[cite: 4]
    - 「買條真絲長裙犒賞自己，這是你應得的獎勵。」【立即無風險帶走一整套，尺寸不合免費換】(美妝時尚適用)[cite: 3, 4]

### pattern:
  name: 心理帳戶偷換與未來模擬型 P.S. (附註催單)
  structure: 附註：[重述產品總價/平分天數的代價] ＋ 也就 [一頓日常小開銷的代價] ＋ 卻能幫你 [換來長期的圓滿場景] ＋ 「現在就採取行動！」[cite: 3, 4, 5]
  examples:
    - 「附註：這套個人諮詢課體驗價為 2,400 元。平分到 21 天，一天大約只要 114 元 ── 也就一頓麥當勞的價格（心理帳戶偷換）。你只是把買零食的零錢，投資在一個能幫你少走 3 年彎路的知識武器上。現在就採取行動，給自己一個無風險改變的機會[cite: 3, 4, 5]！」
    - 「P.S. 兩件特惠組能幫你省下一瓶的錢。一瓶放在辦公室桌上隨時急救，一瓶放在家裡包包，恰好是一個秋天的完整防護。與其等到流感來時看病花錢又遭罪（去醫院一次至少幾百元下不來），不如現在就做好肺的保護[cite: 2, 4, 5]。」

## 3. 可執行檢核 (Review Check)
*   結尾是否使用了「如欲購買、歡迎點擊」等軟弱無力、缺乏主導權的字眼[cite: 3, 4]？
*   行動呼籲是否完全圍繞著「承諾與獲得感」，而非「公司要收錢/要發票」的行政手續[cite: 3, 4, 7]？
