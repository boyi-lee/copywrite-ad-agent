# 通用說服框架知識庫 (Persuasion Frameworks)

## framework:
  name: TIPS 大腦情感說服框架
  purpose: 繞過讀者的「廣告胡說探測器」，依序刺激眶額皮質（決策）與邊緣系統（情感），引導受眾從冷漠逐步走向信任與決策[cite: 2, 3]。
  best_for: 中長篇直效銷售文案、Landing Page 段落架構、EDM 序列信、銷售提案簡報[cite: 2, 3]。
  not_good_for: 簡短的 App Push 提醒、純視覺字卡廣告[cite: 2]。
  steps:
    - Step 1: Tempt (誘惑) -> 利用好奇心、反常識或痛點提問（3個消費者在意的問題），強行中斷受眾的機械滑屏幕反應，給予其必須開始閱讀的理由[cite: 2, 3, 5]。
    - Step 2: Influence (影響) -> 隱藏直接銷售意圖。透過編織一個與用戶畫像高度共鳴的故事、場景或行業現狀，讓其進入短暫的沉浸狀態，微妙地影響其大腦邊緣系統[cite: 2, 3]。
    - Step 3: Persuade (說服) -> 將故事轉化為受眾自身的智理邏輯。引入科學論點、3+5賣點直白轉譯、客觀對比或權威背書，化解其反駁心理，建立不可替代性（USP）[cite: 2, 3, 4]。
    - Step 4: Sell (銷售) -> 執行 4R 成交準則（Repeat 複述故事、Remind 提醒效益、Reassure 消除花錢罪惡感、Relieve 釋放資金），給予正當消費或行動理由，引導明確的下一步[cite: 2, 3]。
  example_application:
    - Tempt: 為什麼有些創作者每天下班後抓頭苦思 3 小時，寫出來的文章點閱率還是不慍不火[cite: 2, 4]？
    - Influence: 其實寫不出爆款真的不是你的錯。我以前也是這樣，收拾好桌面，沖了一杯咖啡，對著空白的 Word 檔案大腦也是一片空白，只能乾巴巴地講大道理，結果讀者看了一秒就關掉[cite: 2, 4, 7]。
    - Persuade: 寫作的本質是組合，而不是憑空發明。這套寫作技能庫將複雜的敘事拆解成 31 個可直接套用的無意識心理拉桿，經過 MarTech 數據測試，能讓文字的可讀性大幅提升[cite: 2, 3, 4]。
    - Sell: 經營個人品牌不用靠運氣。今天加入寫作社群，每天平分下來只要不到 10 塊錢，也就一杯黑咖啡的代價，卻能幫你換來一套一輩子受用的吸金文字觀念，無風險給自己一個改變的機會[cite: 2, 4]。
  risks: 若第一步誘惑過於誇大而第三步無法給出嚴謹證據支持，會導致反駁機制全面啟動，產生公關信任災難[cite: 2, 3]。
  source_ids: [SRC_001, SRC_002, SRC_003]

## framework:
  name: PAS問題煽動框架 (Problem, Agitate, Solve)
  purpose: 透過將隱性問題（Latent Problem）擴散放大至不可忽視的程度，強烈觸發人類「逃避痛苦」的防禦開關，迫使其尋求改變[cite: 2, 4]。
  best_for: TOFU 冷受眾文案、功能型產品頁、B2B SaaS 痛點喚醒、募資文案[cite: 4, 7]。
  not_good_for: 熟客回購通知、高端品牌極簡奢華美學形象海報[cite: 2, 7]。
  steps:
    - Step 1: Problem (定義問題) -> 清楚、具體地指出受眾生活中確實存在、卻往往能拖就拖的特定苦惱或不便（弗雷德抽象問題）[cite: 2, 4]。
    - Step 2: Agitate (煽動/放大後果) -> 在傷口上灑鹽。運用具體的動詞與場景，指出該問題如果不立即解決，會導致何種受眾無法承受的連帶嚴重後果、連帶金錢或形象成本損失[cite: 2, 3, 4, 7]。
    - Step 3: Solve (解決方案) -> 拋出救生圈。引出產品或服務，向其證明這是解決該痛苦、跨越懸崖的唯一無風險橋樑[cite: 4]。
  example_application:
    - Problem: 身為中小企業老闆，每次到了月底，你或你的會計就要面對堆積如山的發票、憑證，手動一筆一筆輸入對帳系統[cite: 2, 4]。
    - Agitate: 這種機械式的機械重複勞動，不僅耗掉你大半的精力，更致命的是人只要一疲憊，就容易出錯。一旦出現小小的對帳手誤，月底報稅被監管機構查核，面臨的可能就是幾十萬元的巨額罰款，甚至讓整間公司的信譽蒙上污點[cite: 2, 3, 4]。
    - Solve: 其實你不用再承擔這種風險。這套自動化財務 SaaS 系統，只要 30 秒就能一鍵核對所有異常帳目，幫你搬開月底忙亂的路障，讓你有時間專注在真正能幫公司賺錢的業務上[cite: 2, 4]。
  risks: 煽動後果時必須遵循 Claim Safety 宣稱安全規則，嚴禁編造不存在的法律或健康威脅（如生命垂危、亡國等）[cite: 2, 5]。
  source_ids: [SRC_001, SRC_003, SRC_004, SRC_005]

## framework:
  name: BAB 橋樑說服框架 (Before, After, Bridge)
  purpose: 運用神經語言程式學（NLP）中的「未來模擬（Future Pacing）」技巧，讓受眾大腦提前體驗到痛苦消失後的圓滿場景，進而對橋樑（產品）產生強烈渴望[cite: 3, 4]。
  best_for: 線上課程介紹、美妝時尚商品頁、個人品牌經營、顧問服務提案[cite: 2, 4, 7]。
  not_good_for: 單純的技術規格手冊、緊急通知[cite: 2, 7]。
  steps:
    - Step 1: Before (現狀/之前) -> 描繪受眾目前被問題困擾、感到挫折、狼狽、不滿的負面生活場景（弗雷德PQR2狀態）[cite: 4]。
    - Step 2: After (願景/之後) -> 翻轉場景。請其想像問題被徹底解決後，過得極為舒適、自豪、或省時省力的理想美妙畫面（大腦獎勵機制活化）[cite: 2, 3, 4]。
    - Step 3: Bridge (橋樑) -> 告訴受眾：要從現狀無縫跨越到那幅理想畫面的最快、最簡單捷徑，就是採用我們的為你準備的解決方案[cite: 4]。
  example_application:
    - Before: 每逢要跟外國客戶進行線上會議，一收到通知，你的胃就開始緊張地翻騰。開會時只能看著螢幕一臉茫然，單字卡在喉嚨裡，只能忍氣吞聲地點頭說 OK，尷尬得想在地上挖個洞跳進去[cite: 2, 3, 4]。
    - After: 想像一下，下次開會時你能夠在螢幕前氣定神閒、用標準地道的語氣跟外國客戶侃侃而談，甚至能用幽默的對話打破僵局，贏得全場同僚投來的羨慕與尊敬眼神[cite: 2, 3, 4]。
    - Bridge: 這種改變不需要你重新去死背十年的單字文法。這套情境會話解方，專為職場高管設計，幫你把複雜的對話濃縮成可隨時取用的核心句型，無風險給自己一個蛻變的機會[cite: 2, 3, 4]。
  risks: 描繪 After 願景時，必須具體且符合用戶利益，切忌使用「讓你煥然一新、帶你走向巔峰」等毫無畫面感的空泛 AI 詞彙[cite: 2, 3, 7]。
  source_ids: [SRC_001, SRC_002, SRC_003, SRC_004]
