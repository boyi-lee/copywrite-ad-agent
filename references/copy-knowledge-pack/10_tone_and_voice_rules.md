# 通用文案語氣與風格規則模組 (Tone & Voice Rules)

## 模組說明
本檔案供 AI Agent 根據 brief 指定的品牌調性與任務需求，調整文字的「情緒濃度」、「詞彙摩擦感」與「專業視角」，嚴禁讓語氣在同一份文案中隨機切換[cite: 3]。

## rule:
  name: 高級感/奢華感品牌語氣 (Premium Brand Voice)
  universal_or_contextual: contextual
  applies_to: 高單價商品、高端專業顧問、個人品牌形象、獨立設計師品牌[cite: 2, 6]。
  not_suitable_for: 快消品限時清倉促銷、B2C 團購大雜燴優惠公告[cite: 2, 7]。
  how_to_apply:
    1. **控制情緒濃度**：大膽採取「收斂取代大聲宣揚」的風格，語氣顯得自信、沉著、不自大[cite: 3]。
    2. **創造高級感**：嚴禁使用「全網最酷、破盤瘋搶、不買後悔」等會激發反駁機制的極限與催促詞[cite: 2, 3, 7]。
    3. **字詞運用**：多使用「內行、質感、一輩子的投資、懂的人就知道、精準、收放自如」[cite: 3, 4, 5]。將焦點從產品本身拉高至「擁有此物後的理想生活美學與社會地位認同」[cite: 2, 3, 6]。
  weak_execution: 「【破盤特價】全網最高規格的高級真皮長皮夾，現在下單打對折，錯過絕對後悔！」[cite: 2, 3, 7]
  strong_execution: 「我們不參與追逐流行的快餐競賽。這款長皮夾採用天然植鞣革，由十幾年老匠人手工理清縫線細節。剛到手時它甚至有些內斂，但隨著你經年累月的使用，皮革會留下專屬於你的溫潤色澤。這不是一季的消耗品，而是一筆低調、內行且值得陪伴一輩子的扎實投資[cite: 2, 3, 4, 5]。」
  review_check: 文案中是否出現了「神級、爆款、瘋搶、划算」等破壞高級感的促銷字眼[cite: 3, 7]？語氣是否能讓受眾感到自豪與自尊（邊緣系統高層次滿足）[cite: 3, 6]？

## rule:
  name: 專業/權威型語氣 (Expert & Authoritative Voice)
  universal_or_contextual: contextual
  applies_to: B2B SaaS、金融理財、健康保健、醫美、法務/會計顧問[cite: 2, 7]。
  not_suitable_for: 潮流美妝時尚社群日常互動貼文、潮流玩具開箱[cite: 2, 7]。
  how_to_apply:
    1. **建立專家人設**：採用「像醫生看病一樣」的兩步診斷邏輯──先精準描述高頻發生的錯誤認知或不滿場景（定義問題），再一針見血地指出元凶與不解決的嚴重後果，最後才給出解決方案（Answer）[cite: 2, 3, 4, 7]。
    2. **科學與數據支持**：大量提供科學常識、 MarTech 數據或權威報告（如TGA/SGS）作為「邏輯（Logos）」論據，讓受眾從理性上接受自己的情感反應[cite: 2, 3]。
    3. **控制字詞**：使用簡短、清晰且不含糊的句子結構，避免囉唆的長篇大論與感傷修辭[cite: 3]。
  weak_execution: 「本公司擁有市場上最完美、技術最卓越的智能自動化財務對帳系統，深受全台各大企業主的一致推薦與好評！」[cite: 2, 3, 7]
  strong_execution: 「在專業財務人士眼裡，月底對帳沒做好，九成以上的帳目異常都是源自人工核對時的疲憊鈍感。這套自動化系統符合歐盟安全合規標準，能在 30 秒內自動比對跨國帳目，把原本需要抓頭苦思 3 天的行政手續，濃縮成一鍵生成的精準儀表板[cite: 2, 3, 4, 5]。」
  review_check: 文案是否在自以為是地強調「我們研發投入了多少資金」（產品思維）[cite: 2]？是否提出了在受眾認知裡成立的客觀評判標準[cite: 4]？

## rule:
  name: 朋友感/社群口語型語氣 (Peer-to-Peer Social Voice)
  universal_or_contextual: contextual
  applies_to: Meta / Instagram 社交廣告、 LINE OA 推播、個人品牌日常觀點分享、電商快消品[cite: 2, 7]。
  not_suitable_for: 企業大額採購招標聲明、法務合約。
  how_to_apply:
    1. **與受眾站在同一陣線**：忘記生硬的官方產品說明，說話要「講人話、講真實內幕」[cite: 2, 3]。像兩位朋友在咖啡廳聊天、分享私藏好物一樣自然[cite: 2, 3]。
    2. **創造字詞摩擦感**：大膽使用「實測、出包、卡卡的、出冷汗、老實說、雷品、超狂」等具有生活畫面感的台灣在地口語[cite: 2, 3, 5]。
    3. **增加對話感**：多用「你字互動」與「 question tag（附加問句）」，例如：「你有多久沒有……」、「……對吧？」[cite: 2, 3]。
  weak_execution: 「【最新公告】本公司特此推出全新研發之機能吸汗運動上衣，具備極佳的排汗透氣性能，歡迎消費者踴躍點擊選購。」[cite: 2, 3, 7]
  strong_execution: 「老實說，這款運動上衣剛拿到手時我也有點懷疑，畢竟外觀跟常規衣服差不多。但這週末穿去跑了一圈，汗一出，衣服完全不黏背、抹一下就乾，手感極為扎實。討厭衣服濕熱黏在背上的朋友，這款真的很值得試試看[cite: 2, 3, 4, 5]。」
  review_check: 檢查是否充斥著「不僅……更是……、致力於、完美融合」等機器人感極強的詞彙[cite: 3, 5]？大聲朗讀時，聽起來是否像一個真人在跟朋友講話[cite: 3, 5]？
