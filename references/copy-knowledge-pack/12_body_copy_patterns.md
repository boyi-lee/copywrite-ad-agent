# 通用正文主文案句型庫 (Body Copy Patterns)

## 模組說明
本檔案提供 AI Agent 撰寫直效文案、社群貼文、 Landing Page 段落與 EDM 正文時，用於段落承接與邏輯推進的「文案連接用語（Connecting Text）」與 Pattern 結構[cite: 4]。

## pattern:
  name: 費時費力代價與專家人設結構 (SRC_001, SRC_004)
  best_for: MOFU 建立信任、高端品牌質感論述、線上課程/專業服務價值轉譯[cite: 2, 4, 7]。
  opening_logic: 透過描述產品背後「真實存在的困難、挑戰、投入與高淘汰成本」，合理化其高溢價，讓受眾看見過程的不容易[cite: 2, 4]。
  structure: |
    [主動拔刺/你可能會懷疑] ＋ [指出研發過程研發人聊天獲得的具體數字細節（花費五個月/打樣了100多次）] ＋ [產品規格] ＋ 「這意味著你……（獲得感具體化）」[cite: 2, 4]
  examples:
    - example:
        industry: 醫美保健
        platform: Landing Page
        funnel_stage: MOFU
        copy_task: 產品研發內文
        text: |
          「你可能會覺得奇怪，為什麼這瓶精華液定價比超市開架品貴了 3 倍？
          
          說實話，這背後沒有什麼神奇的魔法。為了找到能有效改善肌膚粗糙的天然成分，我們的研發總監 Todd 在冷氣房裡研究了市面上 100 多款熱銷品，前後花了兩個月親自試用（細節）。
          
          光是配方調配，實驗室就花了八百天。我們淘汰了將近 90% 的及格樣品，打樣了 100 多次，才定下這個以高分子活性為基底的精純配方。這意味著你連續敷三週，就能在鏡子前肉眼可見地看到肌膚變得光滑細膩，手感好到連你自己都愛不釋手[cite: 2, 4, 5]。」
        why_good_or_bad: 運用「費時費力代價」與「體驗具象化」，將昂貴價格成功反轉為高品質的理性證據[cite: 2, 4]。
        reusable_rule: 拔刺 ＋ 數字與細節具象化 ＋ 獲得感描述（FAB法則）[cite: 2, 4]。
        caution: 數字必須符合 brief 事實，嚴禁 AI 捏造虛假研發數據。

## pattern:
  name: 3M迷思打破與原理解釋結構 (SRC_003, SRC_005)
  best_for: TOFU 冷受眾防禦破冰、內容行銷、個人品牌觀點輸出、B2B SaaS 需求喚醒[cite: 2, 4, 7]。
  opening_logic: 替受眾揪出其長久以來深信不疑、卻對其有害的「錯誤或誤解元凶」，建立專家信譽[cite: 4, 5]。
  structure: |
    [指出受眾常見的盲點/你是不是也以為] ＋ 「其實，在專業人士眼裡，這個錯誤觀念反而會讓你……」 ＋ [產品原理解釋（講人話，用修飾/比喻）] ＋ [引出大品類而非直接急著推銷產品][cite: 2, 3, 4, 5]。
  examples:
    - example:
        industry: 金融理財
        platform: 內容行銷文章
        funnel_stage: TOFU
        copy_task: 正文開場段落
        text: |
          「你是不是也以為，想要提早退休，最好的方法就是把每個月辛苦賺來的工資，乖乖存在利息穩定的建屋互助會裡？
          
          其實，在專業的理財經理眼裡，這種過度追求安全感的慣性思考陷阱，反而正在讓你的資產在通貨膨脹中默默縮水（不處理的後果）。
          
          打個比方，通貨膨脹就像一個看不見的特務，每天都在偷走你口袋裡錢的購買力。想要打破這個僵局，你需要的不是更努力省錢，而是學會使用資產配置的『防護傘』。這份剛出爐的免費資產配置指南，就是教你如何……[cite: 2, 3, 4, 5]」
        why_good_or_bad: 運用比喻（特務、防護傘）將抽象的財金概念講人話，且「先跟受眾聊、聊到心坎裡再給方案」，完全解除戒備[cite: 2, 3, 4]。
        reusable_rule: 揪出元凶 ＋ 講人話修辭 ＋ 延後引出具體方案[cite: 2, 4]。
        caution: 適用於冷受眾，嚴禁一上來就露出產品價格。
