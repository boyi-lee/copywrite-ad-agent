# 受眾意圖與無意識心理模組 (Audience Intent & Psychology)

## rule:
  name: 弗雷德購買動機矩陣應用 (The Fred Motivation Matrix)
  summary: 人類購買任何產品、服務或採取行動的背後，存在 10 大根源動機。文案的任務是將產品特色（Feature）與這些動機進行多元錨定（Multi-anchoring），綁定的動機角（動機夾角）越多，說服力越牢固。
  universal_or_contextual: universal
  applies_to: 所有產業、TOFU 痛點挖掘、BOFU 價值加權、商品頁文案、銷售提案。
  not_suitable_for: 無（此為底層動機理論）。
  how_to_apply:
    1. **通用原則**：禁止只訴諸單一動機（如只談省錢）。對著產品強迫自己寫出以下動機對應的受眾利益與深層意義。
    2. **核心動機矩陣**：
        - 賺錢 / 省錢 / 省時間 / 省力 / 避免身心痛苦 / 獲得更多舒適感 / 增進健康與清潔 / 獲得讚賞 / 獲得更多愛 / 增加受歡迎程度或社會地位[cite: 4]。
    3. **情境化應用**：
        - *B2B SaaS*：自動排班系統 -> 幫老闆省下時間（省時間），避免排班漏掉法令的罰款恐懼（避免身心痛苦），讓經理有空專注研發新產品（賺錢）。
        - *高端美妝時尚*：抗老精華液 -> 讓你在拍照時像自帶反光板（虛榮/獲得讚賞），28天肌膚毛孔收緊（增進健康），少買一堆遮瑕化妝品的費用（省錢）[cite: 2, 4]。
        - *線上教育課程*：數位行銷課程 -> 幫你獲得升職加薪（賺錢），使用經過驗證的範本直接套用（省力），不用再受刁難客戶與老闆的氣（避免痛苦/社會地位）[cite: 2, 4]。
  weak_execution: 「本課程教授最新數位行銷技巧，內容豐富實用，歡迎報名。」
  strong_execution: 「學會這套 MarTech 數據行銷邏輯，能幫你在下個季度的業績審查中用數據說話，爭取到你應得的加薪（賺錢/社會地位）。我們會直接提供 50 套實戰範本讓你直接複製貼上，省下每天加班改稿的時間，準時回家陪陪家人，不用再受刁難客戶和摳門老闆的氣（省力/避免痛苦/愛）。」
  review_check: 文案中是否只單一強調了價格便宜或功能好？是否有將產品與「安全感、省力、自豪、愛」等 3 個以上的深層動機綁定？
  source_ids: [SRC_001, SRC_003, SRC_004]

## rule:
  name: 假性篩選排他效應 (Implicit Exclusion Pattern)
  summary: 在大眾媒體與社群廣告中，與其對著所有大眾群喊話（導致訊息軟弱無力），倒不如刻意使用特定年齡、身分或高頻發生的「自卑/困擾標籤」進行篩選，符合條件者會自動對號入座、強烈產生「這是在對我說話」的無意識歸屬感。
  universal_or_contextual: contextual
  applies_to: Meta / Google 廣告、EDM 主旨、社群媒體文案、SEO 文章標題。
  not_suitable_for: 必須一網打盡的大眾公共服務公告、合約法務文件。
  how_to_apply:
    1. **通用原則**：採用「看似鎖定目標，實則不然」的手法。挑選一個大眾普遍都有、但每個人都以為只有自己才有的隱密痛點或社會標籤作為開場。
    2. **情境化應用**：
        - *旅遊餐飲（居酒屋）*：不要寫「歡迎光臨」，寫「專為『今天在辦公室累了一整天、只想一個人安靜喝一杯』的職場人準備的隱密角落」[cite: 2, 5]。
        - *時尚美妝*：不要寫「抗老面霜適合所有女性」，寫「給那些『畢業於一流大學、月入十萬、正處於打拼事業關鍵期』的職場媽媽（ Lily 們）」[cite: 2]。
        - *App / 數位產品（記帳SaaS）*：不要寫「理財工具適合所有人」，寫「給那些『每個月一到 24 號，看著信用卡帳單就會倒吸一口涼氣』的月光族」[cite: 4, 5]。
    3. **可執行檢核 (Review Check)**：
        - 文案開頭是否在使用「給所有……、廣大顧客請注意」這種無法讓人對號入座的空泛詞？
        - 篩選條件是否具備台灣社群口語的畫面感？
  weak_execution: 「本餐廳裝潢高級、食材嚴選，適合各界人士聚餐、舉辦宴會。」
  strong_execution: 「包包一扔，鞋子一甩，今天在辦公室忍氣吞聲了一整天，下班後你是不是也只想找個沒有熟人、不用應酬的隱密角落，安靜地喝一杯透心涼的生啤酒？（這裡不賣應酬的場面話，只賣讓你徹底放鬆的私房串燒）」
  review_check: 第一段是否有對準受眾狀態？是否只是在進行大眾廣播？
  source_ids: [SRC_001, SRC_002, SRC_004, SRC_005]
