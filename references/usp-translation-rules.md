# USP Translation Rules

## Core Principle

A USP is not a feature list and a promotion is not automatically a USP.

A usable advertising USP must answer:

Why should this person care now?

## USP Translation Chain

Every important feature should be translated through this chain:

Feature
→ Functional benefit
→ Use case
→ Emotional payoff
→ Buying reason

## Example: Product Feature

Feature:
輕量材質

Functional benefit:
長時間使用或穿著時負擔較低

Use case:
適合通勤、工作、運動、旅行、日常高頻使用，依產品類別調整

Emotional payoff:
使用時少一點卡住、悶住、累贅或麻煩

Buying reason:
如果使用者原本的產品已經造成不便，這項特色就能成為更換、升級或首次購買的理由

## Example: Promotion

Weak:
指定商品 2 件 9 折，3 件 8 折

Better:
適合一次補齊平常單買會猶豫的實穿款，尤其是常穿、好搭、換季會反覆用到的品項。

## USP Types

Use one or more, only when supported by current source material.

### Functional USP

Examples: saves time, reduces effort, improves comfort, increases durability, simplifies setup, improves fit, reduces friction, supports a specific task, protects from a specific condition. Use only source-backed specifics.

### Design or Experience USP

Examples: easier to use, cleaner interface, better styling, more flexible pairing, more intuitive workflow, quieter operation, more compact storage, smoother service experience. Use only source-backed specifics.

### Price or Offer USP

- 單買猶豫，組合更划算
- 高單價品項趁活動入手
- Replenish or replace high-frequency items
- Lower the barrier for first trial
- Bundle complementary items logically
- Make a high-consideration purchase easier to justify

### Timing USP

- 活動倒數, only when deadline is verified
- Seasonal demand
- Event or launch timing
- Replacement cycle
- Gift timing
- Usage occasion
- Problem urgency, only when supported

### Audience USP

- First-time buyers
- Repeat buyers
- Heavy users
- Comparison shoppers
- Gift buyers
- Professionals
- Parents
- Hobbyists
- Budget-conscious shoppers
- Premium shoppers
- Existing customers or retargeting audiences

## Required Rule

For each copy, include at least one specific buying reason.

If the copy can apply to any ecommerce brand by changing only the brand name, it fails.

## Evidence Guardrails

Do not claim exact technology, material, waterproof level, inventory, low stock, bestseller, athlete endorsement, tournament proof, free shipping, member points, or discount unless the current brief, landing page, product page, or asset supports it.

When evidence is missing, use neutral selection logic, scene logic, or browsing logic instead of invented proof.
